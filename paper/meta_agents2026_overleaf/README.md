# Overleaf-ready Meta-Agents Workshop draft

This folder contains a complete LaTeX project for the double-blind Demo Track
submission. Upload the folder contents to Overleaf and set `main.tex` as the
main document.

Contents:

- `main.tex` - paper source with the system and product figures
- `references.bib` - bibliography
- `neurips_2026.sty` - NeurIPS 2026 style
- `efferents_network.png` - Efferents system diagram
- `efferents_product.png` - the Efferents Audit/Observe product screenshot

The product screenshot is cropped in LaTeX so its local filesystem path is not
visible in the double-blind PDF. Do not remove the `trim` and `clip` options
without checking anonymity.
