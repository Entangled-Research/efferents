# Numerical integration lab

A CPU-only experiment with analytic ground truth. Compare Simpson and trapezoid
rules at equal evaluation budgets on three smooth functions. Change interval
count, test another rule, or add difficult functions with known integrals.

Run `efferents trial --submission . --runs 3` for three real, saved experiments.
Run `efferents serve --lab-root lab` to inspect measurements and SVG evidence.
No model credentials or Popper Probe installation are needed for this trial.
